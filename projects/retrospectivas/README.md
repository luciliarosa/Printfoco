# Retrospectivas • Repositório de Projetos

Este diretório organiza as produções audiovisuais de retrospectivas da Printfoco, estruturadas por categoria temática:

## Categorias:
- `infantil/`: Produções com temas infantis, cronologia de desenvolvimento e aberturas personalizadas.
- `adulto/`: Retrospectivas para 15 anos, aniversários e marcos comemorativos com depoimentos e fotos.
- `viagens/`: Edições dinâmicas de registros de viagens de férias e expedições.
