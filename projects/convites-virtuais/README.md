# Convites Virtuais • Repositório de Projetos

Este diretório organiza os projetos de convites virtuais desenvolvidos pela Printfoco, categorizados por tecnologia e formato:

## Estrutura:
- `interativos/`: Convites web responsivos com botões inteligentes (RSVP via WhatsApp, GPS no Google Maps/Waze, contagem regressiva, player de áudio e chave Pix).
- `videos/`: Projetos de edição audiovisual animada com trilha sonora sincronizada para WhatsApp e Stories.
- `imagens/`: Artes gráficas estáticas em alta resolução para envio digital ou impressão profissional.
