# Publicações para Redes Sociais • Repositório de Projetos

Este diretório reúne as artes e peças visuais desenvolvidas para estratégias de comunicação e posicionamento digital:

## Formatos:
- `artes-feed/`: Composições estáticas em alta definição (1080x1350 e 1080x1080) com tipografia corporativa.
- `videos-reels/`: Vídeos dinâmicos em formato vertical (1080x1920) com trilha sonora e legendas estratégicas.
- `carrosseis/`: Peças sequenciais para retenção e salvamento de conteúdo no Instagram e LinkedIn.
