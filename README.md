# Printfoco • Catálogo de Convites Interativos 💌

Este repositório centraliza os projetos de convites interativos digitais responsivos (HTML, CSS e JavaScript) desenvolvidos para a **Printfoco**.

---

## 📂 Estrutura de Pastas

```text
Printfoco/
│
└── Convite Interativo/
    │
    └── Tema Natal/              <-- Convite de Natal da Família (Elaine & Edson, Thor & Jade)
        ├── assets/              <-- Imagens e fotos dos mascotes
        ├── index.html           <-- Estrutura principal do convite
        ├── style.css            <-- Estilos e animações
        ├── script.js            <-- Interatividades, sons e simuladores
        └── README.md            <-- Documentação específica do tema
```
